# แผนที่ตำแหน่งจาก ภ.จว.เชียงราย (Police Map CR)

หน้าเว็บ static สำหรับ GitHub Pages: กรอกพิกัด latitude/longitude ได้หลายจุด ปักหมุดบนแผนที่ และคำนวณระยะเส้นตรงกับทิศจาก ตำรวจภูธรจังหวัดเชียงราย (จุดอ้างอิง) ไม่มี backend และไม่เก็บข้อมูล (ดูหัวข้อ "ความเป็นส่วนตัว" ว่าพิกัดถูกส่งไปที่ใดบ้าง)

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้า |
| `style.css` | หน้าตา (รองรับมือถือและ dark mode) |
| `app.js` | แปลงข้อความเป็นพิกัด คำนวณระยะ วาดแผนที่ (Leaflet หรือ Google) |
| `config.js` | **ไฟล์เดียวที่ต้องแก้**: Google API key, พิกัด ภ.จว., ระยะเตือน |
| `.nojekyll` | ให้ GitHub Pages เสิร์ฟไฟล์ตรง ๆ |

## ความสามารถ

- กรอกพิกัดบรรทัดละจุด: `ละติจูด, ลองจิจูด, ชื่อจุด` คั่นด้วย comma, tab (วางจาก Excel), semicolon หรือช่องว่าง
- นำเข้าไฟล์ CSV และส่งออก CSV (มี BOM ให้ Excel อ่านภาษาไทยได้) พร้อมระยะ ทิศ และลิงก์ Google Maps
- ตรวจข้อมูล: บรรทัดที่อ่านไม่ได้, พิกัดนอกช่วง, สลับ lat/lng ให้อัตโนมัติเมื่อกรอกกลับด้าน, เตือนจุดที่ไกลเกิน 200 กม.
- ตาราง: ระยะเส้นตรง (Haversine, กม.), ทิศ 8 ทิศจาก ภ.จว., ระยะถนนและเวลา (เมื่อกดหาเส้นทาง), ลิงก์ "หมุด" และ "นำทาง" ใน Google Maps
- **แสดงเส้นทางถนนอัตโนมัติ** เมื่อเลือกโหมดถนน มี 3 แบบ:
  - **ไปแต่ละจุด:** เส้นทางถนนจาก ภ.จว. ไปทุกจุด เส้นทางขึ้นทีละเส้นเมื่อได้ผล
  - **วนตรวจ:** ภ.จว. ไปจุด 1, 2, 3 ... ตามลำดับที่กรอกแล้วกลับ ภ.จว. ตารางแสดงระยะแต่ละช่วง ขากลับ และผลรวม (ไม่เกิน 25 จุด)
  - **เส้นตรง (ค่าเริ่มต้นทุกครั้งที่เปิดหน้า):** เส้นประจาก ภ.จว. คำนวณในเครื่อง ไม่ส่งพิกัดออกไป
  - ผลเส้นทางที่เคยหาแล้วถูกเก็บไว้ระหว่างใช้งาน สลับโหมดกลับมาได้ทันที
- **แตะหมุดหรือแถวในตาราง** เพื่อเปิดป๊อปอัปที่มีระยะถนน เวลา และปุ่ม "นำทางจาก ภ.จว." "นำทางจากตำแหน่งฉัน" (ใช้ GPS ของเครื่อง บนมือถือจะเปิดแอป Google Maps) และ "เปิดหมุดใน Google Maps"
- ตารางแบบกระชับ 4 คอลัมน์ (ลำดับ, จุด, ระยะ, ปุ่มนำทาง) ไม่ล้นจอ พิกัดดูได้ในป๊อปอัปและ CSV
- **มือถือ:** แผนที่อยู่บนสุด ตามด้วยผลลัพธ์ แล้วจึงช่องกรอก แตะแถวในตารางแล้วหน้าจอเลื่อนขึ้นไปที่หมุดให้
- ส่งออก CSV มีคอลัมน์ระยะถนนและเวลาด้วย
- ลิงก์ "เปิดเส้นทางวนใน Google Maps" เปิดเส้นทาง ภ.จว. ผ่านทุกจุดแล้วกลับ ภ.จว. (ไม่เกิน 9 จุด ตามข้อจำกัด URL ของ Google)
- แก้พิกัดจุดอ้างอิงได้ในหน้าเว็บ (เก็บในเบราว์เซอร์ผู้ใช้)

## โหมดแผนที่

- **ไม่มี key (ค่าเริ่มต้น):** ใช้ OpenStreetMap ผ่าน Leaflet ใช้ได้ทันที ฟรี
- **มี key:** ใส่ `googleMapsApiKey` ใน `config.js` แล้วหน้าเว็บจะใช้ Google Maps เอง ถ้า key ใช้ไม่ได้จะสลับกลับเป็น OpenStreetMap ภายใน 8 วินาทีพร้อมข้อความแจ้ง

### บริการหาเส้นทาง

| โหมดแผนที่ | ใช้บริการ | หมายเหตุ |
|---|---|---|
| OpenStreetMap | OSRM เซิร์ฟเวอร์สาธิตสาธารณะ (router.project-osrm.org) | ฟรี ไม่ต้องมี key แต่เป็นเซิร์ฟเวอร์สาธิต ไม่รับประกันว่าใช้ได้ตลอด และจำกัด 1 ครั้งต่อวินาที (โหมดไปแต่ละจุด 10 จุดจึงใช้เวลาประมาณ 10 วินาที) |
| Google Maps | Google Directions (ใช้ key เดียวกัน) | ต้องเปิด **Directions API** เพิ่มใน key ถ้าไม่ได้เปิด หน้าเว็บจะใช้ OSRM แทนพร้อมแจ้งเตือน |

เวลาเดินทางเป็นค่าประมาณสำหรับรถยนต์ ไม่รวมสภาพจราจร

### ขั้นตอนสร้าง Google Maps API key

1. เข้า Google Cloud Console สร้าง project และผูก billing account (มีเครดิตใช้ฟรีรายเดือน งานปริมาณนี้ปกติไม่เสียเงิน)
2. APIs & Services > Library > เปิด **Maps JavaScript API** และ **Directions API** (สำหรับเส้นทางถนน)
3. Credentials > Create credentials > API key
4. **จำกัด key (สำคัญ เพราะ key จะอยู่ในหน้าเว็บสาธารณะ):**
   - Application restrictions: Websites > เพิ่ม `https://<github-user>.github.io/*` (และ `http://localhost:*/*` ถ้าจะทดสอบในเครื่อง)
   - API restrictions: เลือกเฉพาะ Maps JavaScript API และ Directions API
5. ตั้ง budget alert ใน Billing ไว้กันค่าใช้จ่ายเกิน
6. ใส่ key ใน `config.js` แล้ว commit

## เผยแพร่ GitHub Pages (ยังไม่ได้ทำ)

แนะนำให้แยกเป็น repo สาธารณะของตัวเอง (เช่น `police-map-cr`) คัดลอกไฟล์ทั้งหมดในโฟลเดอร์นี้ไปที่ root ของ repo แล้วเปิด Settings > Pages > Deploy from branch `main` / root

## ความเป็นส่วนตัว

| ข้อมูล | ไปที่ใด |
|---|---|
| ข้อความที่กรอก, จุดอ้างอิง | localStorage ของเบราว์เซอร์เครื่องนั้น กด "ล้าง" เพื่อลบ |
| พิกัดทุกจุด เมื่อเลือกโหมด "ไปแต่ละจุด" หรือ "วนตรวจ" | บริการหาเส้นทาง: OSRM (router.project-osrm.org, FOSSGIS เยอรมนี) หรือ Google Directions ถ้าใส่ key |
| พิกัดของจุดที่กดปุ่มนำทาง | Google Maps |
| บริเวณแผนที่ที่กำลังดู | เซิร์ฟเวอร์ภาพแผนที่ (OpenStreetMap หรือ Google) |
| IP ผู้เปิดหน้า | GitHub Pages, Google Fonts, cdnjs |

โหมด "เส้นตรง" เป็นค่าเริ่มต้นและไม่ส่งพิกัดออกนอกเครื่อง ถ้าต้องการเส้นทางถนนโดยไม่ส่งพิกัดออกนอกหน่วยงาน ให้ติดตั้ง OSRM บนเซิร์ฟเวอร์ของหน่วยงานเอง แล้วเปลี่ยน `OSRM_URL` ใน `app.js`

## ข้อควรระวัง

- พิกัด ภ.จว.เชียงราย ค่าเริ่มต้น (19.930841, 99.877192 ถนนศูนย์ราชการ) มาจาก OpenStreetMap ควรยืนยันกับหน่วยงานก่อนใช้งานจริง ใน OSM มีอีกจุดชื่อ "Chiang Rai Provincial Police" ที่ถนนรัตนาเขต (19.912260, 99.832796) ซึ่งอาจเป็นที่ตั้งเดิมหรือหน่วยอื่น
- คอลัมน์ "เส้นตรง" คือระยะเส้นตรง ระยะถนนอยู่ในคอลัมน์ถัดไปหลังกดหาเส้นทาง
- ลำดับการวนในโหมดตรวจต่อเนื่องเป็นไปตามลำดับที่กรอก ระบบไม่ได้จัดลำดับให้สั้นที่สุด
- ข้อมูลตัวอย่างในปุ่ม "ตัวอย่าง" เป็นพิกัดโดยประมาณสำหรับสาธิตเท่านั้น
