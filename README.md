# แผนที่ตำแหน่งจาก ภ.จว.เชียงราย (Police Map CR)

หน้าเว็บ static สำหรับ GitHub Pages: กรอกพิกัด latitude/longitude ได้หลายจุด ปักหมุดบนแผนที่ และคำนวณระยะเส้นตรงกับทิศจาก ตำรวจภูธรจังหวัดเชียงราย (จุดอ้างอิง) ไม่มี backend และไม่เก็บข้อมูล (ดูหัวข้อ "ความเป็นส่วนตัว" ว่าพิกัดถูกส่งไปที่ใดบ้าง)

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้า |
| `style.css` | หน้าตา (รองรับมือถือและ dark mode) |
| `app.js` | แปลงข้อความเป็นพิกัด คำนวณระยะ วาดแผนที่ (Leaflet หรือ Google) |
| `config.js` | **ไฟล์เดียวที่ต้องแก้**: Google API key, พิกัด ภ.จว., ระยะเตือน |
| `.nojekyll` | ให้ GitHub Pages เสิร์ฟไฟล์ตรง ๆ |

## ความสามารถ

- **นำเข้าไฟล์ Excel จุดตรวจสัมพันธ์ (.xlsx, .xls, .csv)** ได้ทันที ไม่ต้องแก้ไฟล์:
  - ระบบหาแถวหัวตารางที่มีคอลัมน์ `ละติจูด` และ `ลองติจูด` (หรือ `ลองจิจูด`) เอง แถวชื่อเรื่องด้านบนข้ามให้ อ่านทุกแผ่นงานที่มีหัวตารางนี้มารวมกัน (จับคอลัมน์ตามชื่อหัวคอลัมน์) เซลล์ที่ผสานไว้ เช่น วันที่ ใส่ค่าให้ทุกแถวในช่วงนั้น
  - คอลัมน์ตามไฟล์จริง: `วัน/เดือน/ปี`, `เวลาออกตรวจจุดสัมพันธ์`, `สภ.`, `ยศ ชื่อ - สกุล ร้อยเวร 20`, `ตำแหน่ง ร้อยเวร 20`, `เบอร์โทรร้อยเวร 20`, `สถานที่จุดตรวจสัมพันธ์`, `ละติจูด`, `ลองติจูด` คอลัมน์อื่นที่เพิ่มมาก็แสดงในป๊อปอัปด้วย
  - ชื่อหมุด = คอลัมน์ที่ขึ้นต้นว่า `สถานที่` ใต้ชื่อในตารางแสดง สภ. วันที่ เวลา ป๊อปอัปแสดงทุกคอลัมน์ เบอร์โทรแตะโทรได้
  - วันที่ใน Excel แสดงเป็น ว/ด/ปี พ.ศ. เวลาเป็น ชม:นาที เบอร์โทรที่ Excel ตัดเลข 0 หน้าเติมกลับให้ พิกัดเก็บทศนิยมครบ แถวที่ไม่มีพิกัดข้ามพร้อมแจ้งเตือน
  - ไฟล์อ่านในเบราว์เซอร์ด้วย SheetJS 0.18.5 (โหลดจาก cdnjs เมื่อกดนำเข้าเท่านั้น) ไม่ถูกอัปโหลดไปที่ใด
- **วางข้อความทั้งหมดที่คัดลอกมาลงช่องข้อความ** ปักหมุดทันทีที่วาง (ไม่ต้องกดปุ่ม) ได้ผลเหมือนนำเข้าไฟล์:
  - คัดลอกจาก Excel หรือ Google Sheets ทั้งตาราง มีหรือไม่มีแถวชื่อเรื่องและแถวหัวตารางก็ได้ ถ้าไม่มีหัวตารางและมี 9 คอลัมน์ตามไฟล์จุดตรวจสัมพันธ์ ระบบใช้ชื่อคอลัมน์ของไฟล์นั้นให้
  - ช่องที่มีขึ้นบรรทัดใหม่ในเซลล์ (Excel ใส่เครื่องหมายคำพูด) รวมเป็นบรรทัดเดียว ช่องวันที่ที่ว่าง (เซลล์ผสาน) ใช้วันที่ของแถวก่อนหน้า เลขไทยแปลงเป็นเลขอารบิก
  - ข้อความทั่วไป เช่น จาก LINE `23/10/69 สภ.แม่สาย จุดตรวจตลาด 20.4270 99.8830` ระบบหาคู่พิกัด (ทศนิยม 2 ค่าติดกัน) ในบรรทัดเอง
- **แสดงเฉพาะวันที่ (ค่าเริ่มต้น = วันนี้):** ทั้งไฟล์และข้อความที่วาง ปักหมุดเฉพาะแถวที่วันที่ตรงกับวันที่เลือก ข้อมูลวันอื่นยังอยู่ในช่องข้อความ เปลี่ยนวันที่ได้ (เช่น หลังเที่ยงคืนต้องการดูของเมื่อวาน) หรือเอาเครื่องหมายออกเพื่อแสดงทุกวัน
  - อ่านวันที่ได้ทั้ง `23/10/2569`, `23/10/2026`, `23/10/69`, `23 ต.ค. 69`, `23 ตุลาคม 2569`, `2026-10-23` ถ้าไม่มีแถวของวันที่เลือก ระบบบอกว่าในรายการมีวันที่ใดบ้าง
  - แถวที่ไม่มีวันที่ (เช่น พิมพ์พิกัดเอง) แสดงเสมอ ทุกครั้งที่เปิดหน้า วันที่กลับเป็นวันนี้ของเครื่อง
- กรอกพิกัดบรรทัดละจุดแบบเดิมได้: `ละติจูด, ลองจิจูด, ชื่อจุด` คั่นด้วย comma, tab, semicolon หรือช่องว่าง
- **เลือกจุดไปตรวจ:** แตะช่อง "ตรวจ" หน้าแถว หรือปุ่ม "เลือกตรวจจุดนี้" ในป๊อปอัปหมุด ลำดับที่แตะ = ลำดับที่จะไป หมุดที่เลือกเป็นสีเขียว แล้วกด **นำทางไปจุดที่เลือก** เปิด Google Maps จากตำแหน่งปัจจุบัน แวะทุกจุดตามลำดับ แล้วจบที่ ภ.จว. (เลือกได้ไม่เกิน 9 จุด เพราะลิงก์ Google Maps แวะได้ไม่เกิน 9 จุด, v18) การเลือกเก็บไว้ในเครื่อง กลับมาจากแอปนำทางแล้วยังอยู่
- ตรวจข้อมูล: บรรทัดที่อ่านไม่ได้, พิกัดนอกช่วง, สลับ lat/lng ให้อัตโนมัติเมื่อกรอกกลับด้าน, เตือนจุดที่ไกลเกิน 200 กม.
- ตาราง: **ระยะทางถนนและเวลาจาก ภ.จว.** ทุกจุด (OSRM table 1 คำขอได้ทุกจุด สูงสุด 90 จุดต่อคำขอ) ระหว่างรอหรือคำนวณไม่ได้แสดงระยะเส้นตรงพร้อมคำว่า "เส้นตรง" ทิศ 8 ทิศจาก ภ.จว. ปุ่ม "นำทาง" รายจุดใน Google Maps
- ใต้ชื่อจุดแสดง สภ. วันที่ เวลา ถ้าช่องเวลามีวันที่ซ้ำอยู่ด้วย ตัดวันที่ซ้ำออก
- **แตะหมุดหรือแถวในตาราง** เพื่อเปิดป๊อปอัปที่มีรายละเอียดทุกคอลัมน์ ระยะเส้นตรง ทิศ และปุ่ม "นำทางจากตำแหน่งฉัน" (ใช้ GPS ของเครื่อง บนมือถือจะเปิดแอป Google Maps) และ "เปิดหมุดใน Google Maps"
- **ระยะคิดจาก ภ.จว. (เส้นตรง)** แต่ **ปุ่มนำทางทุกปุ่ม** (ป๊อปอัป ตาราง และจุดที่เลือก) เริ่มจากตำแหน่งปัจจุบันของเครื่อง โดยไม่ใส่ `origin` ในลิงก์ Google Maps หน้าเว็บนี้ไม่ได้ขอสิทธิ์ตำแหน่งเอง
- **รวมหมุดที่อยู่ใกล้กัน** เป็นวงกลมพร้อมจำนวน (Leaflet.markercluster / @googlemaps/markerclusterer) ซูมเข้าหรือแตะกลุ่มเพื่อแยกเป็นหมุดเดี่ยว หมุด ภ.จว. ไม่ถูกรวมกลุ่ม
- ตารางแบบกระชับ 5 คอลัมน์ (ตรวจ, ลำดับ, จุด, ระยะ, ปุ่มนำทาง) ไม่ล้นจอที่ความกว้าง 375 px พิกัดดูได้ในป๊อปอัป
- **มือถือ (จอกว้างไม่เกิน 820 px) จัดลำดับตามการใช้งาน:**
  - มีจุดแล้ว: แผนที่ > ผลลัพธ์และวันที่ > จุดที่เลือกตรวจ > รายการจุด > นำเข้าข้อมูล > ตั้งค่า
  - ยังไม่มีจุด: นำเข้าข้อมูลขึ้นก่อน ซ่อนรายการ แผนที่ไว้ท้าย
  - เมื่อเลือกจุดตรวจแล้ว มีปุ่ม "นำทางไป N จุดที่เลือก" ติดขอบล่างจอ เห็นตลอดขณะเลื่อน
  - แตะแถวในตารางแล้วหน้าจอเลื่อนขึ้นไปที่หมุดให้
- **พิกัดแบบมีอักษรบอกทิศ** อ่านได้ทุกช่องทาง (ไฟล์ วางข้อความ พิมพ์): `20.25697N, 100.41035E`, `20.25697 N 100.41035 E`, `N20.25697 E100.41035`, `20°15'25.1"N 100°24'37.3"E` (S และ W เป็นค่าติดลบ) ใส่ละติจูดและลองจิจูดแยกช่อง หรือรวมในช่องเดียวก็ได้
- **แผนที่แสดงเส้นประจาก ภ.จว. ไปทุกจุดอย่างเดียว** (เอาแถบ เส้นตรง/ไปแต่ละจุดที่เลือก/วนตรวจจุดที่เลือก ใต้แผนที่ออก 23 ต.ค. 2569 v14)
- **หัวตารางกดเรียงได้:** "#" (ลำดับในไฟล์ ค่าเริ่มต้น), "จุด" (ชื่อ ก-ฮ), "ระยะ" (ระยะทางถนนจาก ภ.จว. ใกล้ไปไกล ถ้ายังไม่มีระยะถนนใช้ระยะเส้นตรง) แตะซ้ำเพื่อกลับด้าน เลขหมุดยังเป็นลำดับในไฟล์เสมอ แถวจัดใหม่เฉพาะตอนแตะหัวคอลัมน์ (แตะเลือกจุดหรือระยะถนนคำนวณเสร็จแล้วแถวไม่ย้ายที่) เปิดหน้าหรือนำเข้าข้อมูลใหม่เริ่มที่ "#" เสมอ (v15)
- **คำอธิบายพับเก็บ (v17):** "วิธีนำเข้า", "วิธีใช้รายการและระยะทาง" และ "ความเป็นส่วนตัวของข้อมูล" (ท้ายหน้า) ปิดไว้เป็นค่าเริ่มต้น กดเปิดดูได้ ข้อความแจ้งสถานะและข้อผิดพลาดยังแสดงตามปกติ
- **เวรข้ามวัน (v16):** ตัวกรองเป็น "แสดงเฉพาะเวรวันที่" ไฟล์ลงวันที่ตามวันเริ่มเวร (เช่น เวร 20:00 ถึง 02:00 ลงวันที่ 23 ทั้งเวร) เปิดหน้าก่อน 06:00 ค่าเริ่มต้นเป็นเวรของเมื่อวาน จุดที่เวลาก่อน 06:00 แสดงวันที่จริงกำกับ เช่น "00:30 (24 ต.ค.)" ทั้งในตารางและป๊อปอัป เปลี่ยนเวลาตัดเวรได้ที่ `shiftCutoffHour` ใน `config.js`
- **ปุ่ม "ตัวอย่าง"** ใส่ข้อความแบบง่ายที่สุด บรรทัดละ `ละติจูด, ลองจิจูด` 5 จุด (ไม่มีชื่อ วันที่ หรือคอลัมน์อื่น) ชื่อจุดเป็น "จุดที่ 1" ถึง "จุดที่ 5" อัตโนมัติ (v15)
- **ลำดับการเดินทาง:** ค่าเริ่มต้น = ลำดับที่แตะเลือก เลือกตั้งแต่ 3 จุด มีปุ่ม **จัดลำดับให้ระยะรวมสั้นที่สุด** (OSRM trip: ภ.จว. > จุดที่เลือก > กลับ ภ.จว.) จัดแล้วแถบจุดที่เลือก หมุด และลิงก์นำทางใช้ลำดับใหม่ ถ้าต้องการแก้ลำดับเอง เอาเครื่องหมายออกแล้วแตะใหม่ (จุดที่แตะทีหลังไปทีหลัง)
- **แถบเลือกจุดไปตรวจบอกระยะทางและเวลา** ทุกครั้งที่เลือก: แต่ละจุดบอกระยะถนนและเวลาจากจุดก่อนหน้า (จุดแรกจาก ภ.จว.) แล้วสรุป รวมไป, กลับ ภ.จว., รวมทั้งวง
- ระยะถนนคำนวณด้วย OSRM เซิร์ฟเวอร์สาธิตสาธารณะ (router.project-osrm.org) ส่งพิกัดของจุดในรายการ (ที่แสดงตามวันที่เลือก) และ ภ.จว. ไปคำนวณ เว้นคำขอ 1.1 วินาทีตามนโยบายเซิร์ฟเวอร์ ผลที่เคยคำนวณเก็บไว้ระหว่างใช้งาน เวลาไม่รวมสภาพจราจร ถ้าต้องการไม่ส่งพิกัดออกนอกหน่วยงาน ติดตั้ง OSRM เองแล้วเปลี่ยน `OSRM_URL` ใน `app.js`
- เอาออกแล้ว 23 ต.ค. 2569: ปุ่มส่งออก CSV, ปุ่ม "ดูทุกจุด", ลิงก์ "เปิดเส้นทางวนใน Google Maps", ปุ่ม "ใช้ลำดับนี้กับรายการ" (การจัดลำดับสั้นที่สุดกลับมาเป็นปุ่มในแถบจุดที่เลือก v14), Google Directions (ใช้ OSRM อย่างเดียว)
- แก้พิกัดจุดอ้างอิงได้ในหน้าเว็บ (เก็บในเบราว์เซอร์ผู้ใช้)

## โหมดแผนที่

- **ไม่มี key (ค่าเริ่มต้น):** ใช้ OpenStreetMap ผ่าน Leaflet ใช้ได้ทันที ฟรี
- **มี key:** ใส่ `googleMapsApiKey` ใน `config.js` แล้วหน้าเว็บจะใช้ Google Maps เอง ถ้า key ใช้ไม่ได้จะสลับกลับเป็น OpenStreetMap ภายใน 8 วินาทีพร้อมข้อความแจ้ง

### ขั้นตอนสร้าง Google Maps API key

1. เข้า Google Cloud Console สร้าง project และผูก billing account (มีเครดิตใช้ฟรีรายเดือน งานปริมาณนี้ปกติไม่เสียเงิน)
2. APIs & Services > Library > เปิด **Maps JavaScript API** และ **Directions API** (ไม่จำเป็นแล้ว เพราะเอาโหมดเส้นทางถนนออก)
3. Credentials > Create credentials > API key
4. **จำกัด key (สำคัญ เพราะ key จะอยู่ในหน้าเว็บสาธารณะ):**
   - Application restrictions: Websites > เพิ่ม `https://<github-user>.github.io/*` (และ `http://localhost:*/*` ถ้าจะทดสอบในเครื่อง)
   - API restrictions: เลือกเฉพาะ Maps JavaScript API และ Directions API
5. ตั้ง budget alert ใน Billing ไว้กันค่าใช้จ่ายเกิน
6. ใส่ key ใน `config.js` แล้ว commit

| IP ผู้เปิดหน้า | GitHub Pages, Google Fonts, cdnjs |

ทิศและระยะเส้นตรงคำนวณในเครื่อง พิกัดออกไป 2 ทาง: จุดในรายการไป OSRM เพื่อคำนวณระยะทางถนนและเวลา และตอนกดปุ่มนำทางไป Google Maps

## ข้อควรระวัง

- พิกัด ภ.จว.เชียงราย ค่าเริ่มต้น (19.930841, 99.877192 ถนนศูนย์ราชการ) มาจาก OpenStreetMap ควรยืนยันกับหน่วยงานก่อนใช้งานจริง ใน OSM มีอีกจุดชื่อ "Chiang Rai Provincial Police" ที่ถนนรัตนาเขต (19.912260, 99.832796) ซึ่งอาจเป็นที่ตั้งเดิมหรือหน่วยอื่น
- ระยะทางถนนคิดจาก ภ.จว. จึงต่างจากระยะที่ Google Maps แสดงตอนนำทาง (ซึ่งเริ่มจากตำแหน่งปัจจุบันและใช้ข้อมูลถนนของ Google)
- OSRM เซิร์ฟเวอร์สาธิตไม่รับประกันว่าใช้ได้ตลอด ถ้าคำนวณไม่ได้ หน้าเว็บแจ้งข้อความและยังนำทางได้ตามปกติ
- ข้อมูลตัวอย่างในปุ่ม "ตัวอย่าง" เป็นพิกัดโดยประมาณสำหรับสาธิตเท่านั้น
